# Triage Labels

这些技能使用五个规范化的 triage 角色。本文件把这些角色映射到当前仓库实际使用的状态字符串。

| 技能中的标签 | 仓库中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要先评估这个 issue |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已经足够完整，可交给 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当某个技能提到 triage 角色时，使用上表右侧的实际字符串。

如果你以后想改用自己的命名，只需要修改右侧这一列。

# 视觉方向与招聘叙事结论

对应 issue: `#1 视觉方向确认与招聘叙事对齐`

## 1. 结论摘要

第一版个人品牌站的视觉方向确定为:

- `克制的未来感`
- `高级技术质感`
- `招聘可读性优先`
- `专业可信 + 有技术锋芒`

它不是传统意义上的炫技作品集，也不是朴素到没有记忆点的简历镜像页，而是一种面向招聘场景的高质量技术品牌表达: 第一眼先让招聘方快速确认“这是一位当前定位清晰、工程能力可信、并且具备跨领域技术深度的人”，第二眼再感受到他在 AI、多媒体、Web3D、VR 和工程系统之间建立起来的差异化能力。

## 2. 招聘叙事定位

### 2.1 目标岗位

首页首屏优先传达的岗位定位统一为:

- `AI 智能体工程师`
- `AI 应用 / 工作流工程师`
- `全栈开发工程师`

对外叙事上，这三个定位不应并列得过于松散，而应收束为一句主张:

> 以 AI 应用和智能体为当前主定位，以全栈工程落地为交付能力，以 VR / Web3D / 工业系统背景作为差异化深度。

### 2.2 需要在首屏回答的问题

招聘方在进入首页的前 5-10 秒内，应当得到以下答案:

1. 这个人现在想应聘什么岗位
2. 这个人的核心能力是 AI 应用落地，而不是停留在概念演示
3. 这个人有完整工程经验，能做系统、能做产品、也能处理复杂技术场景
4. 这个人与普通前端作品集候选人的区别，在于其跨域背景和技术演进路径

### 2.3 叙事主线

整站叙事采用以下主线:

`工业/系统软件与交互技术背景 -> Web3D / VR / 多媒体能力 -> AI 应用与智能体工程化 -> 面向业务与产品交付的复合型工程师`

这个顺序很重要。它能把“经历很多方向”解释为“能力持续演进”，而不是“方向分散”。

## 3. 首页首屏策略

### 3.1 首屏必须优先传达的信息

首屏内容优先级固定为:

1. `当前岗位定位`
2. `一句话价值主张`
3. `差异化标签`
4. `核心行动按钮`

建议的一句话结构:

> 面向 AI 应用、智能体与全栈交付的工程师，具备 Web3D、VR、多媒体与工业系统背景，能够把复杂技术能力整合成可落地的产品体验。

### 3.2 首屏 CTA

首屏至少保留以下 CTA:

- `查看项目主题`
- `下载 PDF 简历`
- `GitHub / Email`

CTA 的角色是服务招聘转化，不是引导用户“玩页面”。因此按钮文案应直接、明确、可预期。

### 3.3 首屏视觉表达

首屏不使用单一头像主视觉，也不使用单个项目截图霸占画面。

应采用“多域技术意象拼合”的方式，传达以下几类信号:

- AI 工作流 / 节点 / 推理与协作感
- 多媒体与视频生成的节奏感
- Web3D / 空间结构 / 透视深度
- 工程系统 / 仪表 / 控制与稳定性

最终效果应更像“技术能力图谱的高端品牌化表达”，而不是“某个 demo 的封面海报”。

## 4. 视觉系统方向

### 4.1 Typography

Typography 的关键词:

- `清晰`
- `压缩感`
- `专业编辑感`
- `技术品牌感`

具体原则:

- 标题字体应有明确个性，略带工业或科技出版物气质，避免通用模板字体导致的平庸感
- 正文字体以高可读性为先，中文阅读体验必须稳定，不能为了“未来感”牺牲招聘阅读效率
- 中英混排需要自然，英文可承担少量品牌感，中文承担主体信息可读性
- 首屏大标题允许更强的字重和节奏变化，但正文、经历、项目摘要必须保持规整

Typography 结论:

`标题负责建立品牌锋芒，正文负责建立可信度。`

### 4.2 色彩气质

色彩关键词:

- `深色中性底`
- `冷静金属感`
- `低饱和科技色点缀`
- `少量高亮强调`

建议方向:

- 背景以深石墨、蓝灰、冷黑为主，形成稳重与技术深度
- 主强调色可以在冰蓝、青蓝、冷青绿之间选择，而不是廉价霓虹紫
- 次级强调色可少量引入暖金属色或浅银色，用于高级感平衡
- 色彩应更像“精密仪器 / 专业软件 / 高端技术品牌”，而不是游戏海报

色彩结论:

`配色要先服务可信与高级，再服务炫酷。`

### 4.3 页面氛围

页面氛围关键词:

- `安静但有张力`
- `精密但不冰冷`
- `未来感但克制`
- `高级但不疏离`

建议通过以下方式建立氛围:

- 使用分层背景、微弱渐变、结构线、网格、模糊光斑，而不是大面积发光特效
- 用留白、版式节奏和模块密度建立“高级感”
- 用少量动效体现技术感，例如 staged reveal、缓慢位移、层次浮动
- 用卡片、时间线、主题分组建立专业信息秩序

## 5. 品牌边界

### 5.1 应强调的品牌印象

这个站应该让人联想到:

- `可信任的工程师`
- `有作品判断力的技术人`
- `跨领域整合能力强`
- `能把新技术做成业务结果`

### 5.2 不应该越过的边界

必须避免把品牌做成以下方向:

- 过于年轻化或潮流海报化，损失招聘可信度
- 过于冷淡和企业官网化，失去个人辨识度
- 过度强调“会很多技术名词”，变成关键词堆砌
- 过度包装 AI 概念，而缺少工程落地信号

边界结论:

`品牌表达可以锋利，但不能轻浮；可以前沿，但不能悬浮。`

## 6. 明确要避免的风格误区

以下风格明确列入禁区:

### 6.1 模板化作品集感

典型问题:

- 一眼看上去像常见前端 portfolio 模板
- hero、skills、projects、contact 的布局毫无叙事策略
- 视觉语言只是在“好看”，没有服务招聘场景

避免原则:

`首页必须像一份被精心设计过的招聘叙事界面，而不是组件拼装页。`

### 6.2 过度炫技

典型问题:

- 复杂 3D 动效抢走正文信息
- 滚动效果过重，影响阅读效率
- 首屏像展示技术能力而不是解释候选人价值

避免原则:

`动效和技术展示只能加分，不能阻碍招聘者获取信息。`

### 6.3 廉价赛博风

典型问题:

- 紫蓝霓虹泛滥
- 发光描边过多
- 噪点、扫描线、故障风堆砌
- 给人“学生作品”或“概念海报”的感觉

避免原则:

`科技感来自秩序、材料感和节奏，不来自特效堆积。`

### 6.4 过度简历化

典型问题:

- 只是把 PDF 简历网页化
- 信息正确但没有品牌层次
- 无法体现候选人的技术演进和差异化主题

避免原则:

`这是招聘导向的品牌站，不是简历截图容器。`

## 7. 首页信息架构判断标准

后续设计与实现时，首页每一部分都应通过以下判断:

1. 是否强化了当前目标岗位定位
2. 是否帮助招聘方更快理解候选人的可信能力
3. 是否把过往 VR / Web3D / 工业系统经验解释成“当前 AI 与全栈能力的独特支撑”
4. 是否维持了统一的高级技术品牌气质
5. 是否避免落入模板感、炫技感、廉价赛博感

如果某个设计决策不能同时满足其中至少前三条，就不应进入第一版。

## 8. 对后续实现的直接约束

这份结论对后续页面实现提出以下硬约束:

- 首屏标题和副标题必须明确当前岗位定位，不能只写泛化自我介绍
- 首页视觉核心必须是“多域能力整合”，不能退化成单一项目封面
- 视觉 token 需要先定义 typography、color、surface、motion，再进入组件实现
- 所有页面的动效默认从轻，只有在不影响阅读时再增加层次
- 项目主题文案必须服务招聘叙事，不能只是 repo 名称罗列
- 移动端仍需保持“高级且可信”的气质，不能因为压缩布局而变成普通卡片流

## 9. 最终一句话判断

第一版个人品牌站的正确方向是:

> 用克制而高级的技术品牌视觉，把“AI 应用 / 智能体 / 全栈工程”作为当前主叙事，把 VR、Web3D、多媒体与工业系统经历转化为可信且稀缺的差异化背书。
